watched repositories

agents

An agent is one of your skills running over the PR. The list starts empty: build yours below, out of what is installed on this machine. The first one is the default. Not every skill produces a review — turn ⇧ output can go to the PR off on the ones that don't, and Bazel stops offering to publish them.

pipelines

A pipeline runs agents one after another over the same clone — the repository is cloned once and each step reads it in turn. Their reports come back stacked in one card. Only the steps whose output can go to the PR are published.
Drag from the tray into the chain to add a step, and drag a step to move it.

installed skills

use makes an agent that hands the review back for you to read; ⇧ publishes makes one that posts straight to the PR.
